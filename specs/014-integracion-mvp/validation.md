## Alcance y límites

Todos los pacientes/notas del recorrido son ficticios y locales. Identidad/correo del harness simulados; HTTP, servicios, repositorios y PostgreSQL reales. No se ejecuta Supabase, db:check remoto ni Resend en esta etapa. El piloto real anterior solo acredita registro/confirmación/contraseña+código/logout; recuperación real diferida y AUTH T7 no completada.

Se sustituyó temporalmente la API real propia por la demo ficticia aislada para la comprobación visual, sin detener procesos ajenos; se restauró el servidor normal al terminar y la UI quedó en Ingresar sin banner simulado. Sin instalaciones ni nuevos correos. Cambios locales de AUTH (006, DATABASE, bloque extra del runner y migración renombrada) excluidos del commit de integración. DECISIONS se selecciona parcialmente.

No se detectaron defectos nuevos del producto en el recorrido HTTP. Se corregían afirmaciones obsoletas de la guía, sin reescribir decisiones históricas. Las pruebas automatizadas de UI conservadas usan contratos simulados y no se presentan como prueba de persistencia; esa evidencia corresponde al recorrido HTTP/PostgreSQL y la demo local.
