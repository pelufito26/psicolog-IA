# Documentación de PsicologIA

Esta carpeta contiene la documentación funcional y técnica del proyecto PsicologIA.

Su propósito es establecer una fuente de verdad para el desarrollo asistido por IA.

## Documentos previstos

- PRODUCT.md — Visión y alcance del producto.
- USE_CASES.md — Casos de uso del MVP.
- DOMAIN.md — Modelo de dominio y reglas de negocio.
- ARCHITECTURE.md — Arquitectura y stack tecnológico.
- DECISIONS.md — Decisiones funcionales y técnicas.
- SECURITY.md — Seguridad y confidencialidad.

## Principios

- La documentación aprobada guía la implementación.
- Los agentes de IA deben consultar los documentos relevantes antes de desarrollar.
- Las decisiones pendientes no deben asumirse como confirmadas.
- Los cambios funcionales o arquitectónicos deben reflejarse en la documentación.
